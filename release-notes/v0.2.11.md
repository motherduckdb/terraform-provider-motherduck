## Highlights

- Follow complete examples from provisioning through reader setup, token rotation, runtime workloads and teardown. A Registry guide links the version-pinned projects. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.10...v0.2.11)

## Features

- Audit direct role membership and inheritance against explicit policy, separately from share audiences. Reject persistent drift even after the report is saved. [Role audit](https://github.com/motherduckdb/terraform-provider-motherduck/blob/v0.2.11/examples/role-access-audit/README.md)
- Suspend tenant access without deleting its data, then reactivate it through the customer-facing analytics example. The Node companion uses separate reader pools, verified TLS and parameterized queries. [Tenant workflow](https://github.com/motherduckdb/terraform-provider-motherduck/blob/v0.2.11/examples/customer-facing-analytics/README.md)
- Pass a Terraform-owned database into a pinned dlt cookbook, dbt models and an explicitly deployed Flight without giving multiple tools ownership of the same tables. [Pipeline workflow](https://github.com/motherduckdb/terraform-provider-motherduck/blob/v0.2.11/examples/cookbook-pipeline/README.md)

## Compatibility

- Provider schemas and import formats are unchanged. The writer-bootstrap module includes a moved block for its original token resource address. Tenant modules add reader setup tokens and explicit Standard read-pool settings, so review an upgrade plan before applying to existing readers. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.10...v0.2.11)
- Terraform 1.5 or later remains supported. The runnable projects are in GitHub, linked from the Registry documentation, and are not separately published Registry modules. [Example guide](https://github.com/motherduckdb/terraform-provider-motherduck/blob/v0.2.11/docs/guides/examples.md)
