## Highlights

- Respect canceled SQL requests before starting an operation, and reduce allocation overhead when converting mixed-value catalog rows. [#37](https://github.com/motherduckdb/terraform-provider-motherduck/pull/37)

## Bug Fixes

- Check context cancellation before every SQL attempt, including the first, so expired or canceled requests do not start unnecessary work. Already-running operations still rely on the underlying client for cancellation. [#37](https://github.com/motherduckdb/terraform-provider-motherduck/pull/37)

## Maintenance

- Avoid failed JSON-to-string decoding for numeric, boolean, and structured catalog values while preserving their representation. A local 1,000-row mixed-value benchmark used about 24% less conversion time and 25% fewer allocations. This does not measure query or total apply latency. [#37](https://github.com/motherduckdb/terraform-provider-motherduck/pull/37)
- Separate Dive, Flight, and Flight-run implementations into focused files, with all 64 declarations preserved. [#37](https://github.com/motherduckdb/terraform-provider-motherduck/pull/37)

## Tooling and Release

- Consolidate 31 no-op plan assertions and verify equivalent command output, argument handling, exit status, and cleanup across 124 comparisons. Add cancellation regressions and a catalog conversion benchmark. [#37](https://github.com/motherduckdb/terraform-provider-motherduck/pull/37)
