Release notes for the first release, v0.1.0. Publication is established by the signed GitHub release and Registry listing, not this file.

## Highlights

- Manage MotherDuck SQL infrastructure and REST administration from Terraform. [Initial public source](https://github.com/motherduckdb/terraform-provider-motherduck/commit/383212c5358d169dcd2203dc6d49a781c5513f1c)
- Read sensitive typed Flight logs while retaining raw JSON access. [#8](https://github.com/motherduckdb/terraform-provider-motherduck/pull/8)

## Features

- Includes databases, schemas, tables, views, secrets, shares, snapshots, roles, Guides, Dives, Flights, service accounts, access tokens, and Duckling configuration. [Initial public source](https://github.com/motherduckdb/terraform-provider-motherduck/commit/383212c5358d169dcd2203dc6d49a781c5513f1c)

## Bug Fixes

- Changing Flight-run wait status, timeout, or polling interval no longer replaces the resource and reruns the Flight. Settings apply on creation; updates preserve the existing execution. [#12](https://github.com/motherduckdb/terraform-provider-motherduck/pull/12)

- Restores the selected database after cancellation, preserves exact catalog integers, and applies Flight wait deadlines to SQL status queries. [#9](https://github.com/motherduckdb/terraform-provider-motherduck/pull/9)

## Maintenance

- Reduces catalog scan allocations and shares cancellation-aware retry delays. [#9](https://github.com/motherduckdb/terraform-provider-motherduck/pull/9)

- Centralizes nullable JSON decoding for Flight and Guide state. [#5](https://github.com/motherduckdb/terraform-provider-motherduck/pull/5)
- Updates the Go toolchain and gRPC dependency, including upstream security fixes. [#8](https://github.com/motherduckdb/terraform-provider-motherduck/pull/8)

## Tooling and Release

- Installs native release ZIPs through Terraform on all supported platforms, strengthens lifecycle/import tests, and documents setup, state, architecture, and publishing prerequisites. [#9](https://github.com/motherduckdb/terraform-provider-motherduck/pull/9)

- Adds hermetic Terraform lifecycle contracts and trusted live SQL checks. [#6](https://github.com/motherduckdb/terraform-provider-motherduck/pull/6)
- Tests Terraform through 1.16.1 while retaining earlier compatibility lanes. [#8](https://github.com/motherduckdb/terraform-provider-motherduck/pull/8)

## Compatibility

- Infrastructure provisioning is the recommended default. Flight definitions and schedules are an optional Terraform ownership model; Dive and Guide resources are experimental and outside the stable support commitment. Existing resource registrations remain available. [#12](https://github.com/motherduckdb/terraform-provider-motherduck/pull/12)
- Flight-run resources are deprecated in favor of explicit CLI/SQL or deployment-pipeline execution. Follow the state-only migration guide to avoid unintended cancellation or deletion. [#12](https://github.com/motherduckdb/terraform-provider-motherduck/pull/12)

- Terraform 1.5 or later is the general baseline; ephemeral resources require Terraform 1.10 or later. Native packages target Linux and macOS on amd64 and arm64. [Initial public source](https://github.com/motherduckdb/terraform-provider-motherduck/commit/383212c5358d169dcd2203dc6d49a781c5513f1c)
