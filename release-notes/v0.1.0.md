## Highlights

- Introduces the MotherDuck Terraform provider for REST-backed organization administration and SQL-backed database, schema, table, view, secret, share, snapshot, Dive, and Flight workflows. [983752f](https://github.com/motherduckdb/terraform-provider-motherduck/commit/983752fc751211044c55fca23f58e64933b33ddf)
- Ships the first tag-driven provider release with native packages, checksums, GPG signature support, and Terraform Registry manifest assets. [fd43fce](https://github.com/motherduckdb/terraform-provider-motherduck/commit/fd43fce423bd91e7101c87e5876924d92f3f9a1c) [f74f02f](https://github.com/motherduckdb/terraform-provider-motherduck/commit/f74f02f0797ce143886cc1791aaf413a032f46f9)

## Features

- Adds provider configuration, generated docs, examples, and test fixtures for MotherDuck resources and data sources. [983752f](https://github.com/motherduckdb/terraform-provider-motherduck/commit/983752fc751211044c55fca23f58e64933b33ddf)
- Adds reusable hypertenancy and read-hypertenancy blueprint modules for tenant-isolated read/write patterns. [983752f](https://github.com/motherduckdb/terraform-provider-motherduck/commit/983752fc751211044c55fca23f58e64933b33ddf)
