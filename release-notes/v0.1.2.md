## Highlights

- Updates the embedded DuckDB client to 1.5.5 now that MotherDuck accepts 1.5.5 connections. [#31](https://github.com/motherduckdb/terraform-provider-motherduck/pull/31)
- Adds Terraform management for MotherDuck Dive `draft`, `ready`, `endorsed`, and `archived` status transitions. [#21](https://github.com/motherduckdb/terraform-provider-motherduck/pull/21)
- Adds MotherDuck Guides, custom roles and role grants, role-aware share grants, filtered-share patterns, and expanded Guide, Flight, role, and share data sources. [#25](https://github.com/motherduckdb/terraform-provider-motherduck/pull/25)
- Fixes SQL identifier handling and Terraform state consistency across databases, tables, views, shares, grants, and snapshots. [#36](https://github.com/motherduckdb/terraform-provider-motherduck/pull/36) [#43](https://github.com/motherduckdb/terraform-provider-motherduck/pull/43)
- Moves role and role-grant reads to the documented MotherDuck `SHOW` commands. [#42](https://github.com/motherduckdb/terraform-provider-motherduck/pull/42)
- Defers cross-field validation until referenced Terraform values are known, allowing valid database and Duckling configurations to complete planning. [#24](https://github.com/motherduckdb/terraform-provider-motherduck/pull/24)
- Fixes Flight run waiting for the public enum-style status values returned by MotherDuck. [#17](https://github.com/motherduckdb/terraform-provider-motherduck/pull/17)

## Features

- Adds the `status` attribute to `motherduck_dive`, with create and update support for `draft`, `ready`, `endorsed`, and `archived` states. [#21](https://github.com/motherduckdb/terraform-provider-motherduck/pull/21)
- Adds `motherduck_guide`, `motherduck_role`, and `motherduck_role_grant` resources, plus Guide and role catalog data sources. [#25](https://github.com/motherduckdb/terraform-provider-motherduck/pull/25)
- Adds role principals to `motherduck_share_grant`, in-place `include_pattern` updates to `motherduck_share`, and owner filtering to Flight listings. [#25](https://github.com/motherduckdb/terraform-provider-motherduck/pull/25)

## Bug Fixes

- Normalizes enum-style Flight run statuses before wait and failure comparisons, preventing successful runs from timing out and treating enum-style failures as terminal. [#17](https://github.com/motherduckdb/terraform-provider-motherduck/pull/17)
- Emits an explicitly typed empty resource-list literal when a Dive has no `required_resources`, avoiding ambiguous DuckDB SQL binding. [#17](https://github.com/motherduckdb/terraform-provider-motherduck/pull/17)
- Hardens REST response limits, retry delays, timeout arithmetic, token handling, SQL token redaction, and table type validation. [#19](https://github.com/motherduckdb/terraform-provider-motherduck/pull/19)
- Initializes recycled DuckDB/MotherDuck connections with the current Terraform operation context and retries transient initial client creation failures. [#20](https://github.com/motherduckdb/terraform-provider-motherduck/pull/20)
- Defers DuckLake and Pulse cooldown cross-field checks when their controlling Terraform values are unknown. [#24](https://github.com/motherduckdb/terraform-provider-motherduck/pull/24)
- Keeps service accounts in state unless a routed REST endpoint confirms they no longer exist. [#35](https://github.com/motherduckdb/terraform-provider-motherduck/pull/35)
- Quotes literal and qualified SQL identifiers separately, preserving dotted principals and column names while keeping database paths correctly qualified. [#36](https://github.com/motherduckdb/terraform-provider-motherduck/pull/36)
- Reads roles and role grants through `SHOW ALL ROLES` and `SHOW ROLES TO`, and aligns custom role-name validation with the documented contract. [#42](https://github.com/motherduckdb/terraform-provider-motherduck/pull/42)
- Prevents omitted share options and nullable database fields from corrupting Terraform state, recovers share grants after out-of-band share deletion, and checks post-write reads. [#43](https://github.com/motherduckdb/terraform-provider-motherduck/pull/43)
