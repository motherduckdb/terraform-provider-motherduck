## Highlights

- Provider binaries are built with Go 1.27.3, which fixes [GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809) (CVE-2026-111943) in `crypto/x509`. Go 1.27.2 trusted compromised intermediate certificates when it verified TLS connections, including the HTTPS connections that the provider opens to the MotherDuck REST API. [Change](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.3.6...v0.3.7)
- Go dependencies, release workflow actions and example lock files are updated to their latest compatible releases. No known vulnerabilities are reported for the provider or the examples. [Change](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.3.6...v0.3.7)

## Upgrading from v0.3.6

Version constraints such as `~> 0.3.0` select this release. No configuration changes are required.

1. Run `terraform init -upgrade`.
2. Run `terraform plan` and review the plan before applying it.
3. Update pinned refs and module sources that reference `v0.3.6`.

## Compatibility

- Resource schemas, import formats and the provider source address are unchanged. The embedded DuckDB client remains on version 1.5.6, because the provider embeds a DuckDB version only after MotherDuck supports it. [Change](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.3.6...v0.3.7)
