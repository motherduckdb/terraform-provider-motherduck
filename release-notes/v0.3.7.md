## Highlights

- Provider binaries are built with Go 1.27.3, which fixes [GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809) (CVE-2026-111943) in `crypto/x509`. Go 1.27.2 still trusted compromised intermediate certificates when verifying TLS connections, including the provider's HTTPS calls to the MotherDuck REST API. [Change](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.3.6...v0.3.7)
- Go dependencies, release workflow actions and example lock files are updated to their latest compatible releases. `govulncheck` and `pip-audit` report no known vulnerabilities. [Change](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.3.6...v0.3.7)

## Upgrading

Run `terraform init -upgrade` and review `terraform plan`. Constraints such as `~> 0.3.0` select this version. No configuration changes are needed.

## Compatibility

- Resource schemas, import formats and the provider source address are unchanged. The embedded DuckDB client stays on 1.5.6 because MotherDuck must accept a DuckDB version before the provider embeds it. [Change](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.3.6...v0.3.7)

## Maintenance

- Go dependencies are updated to their latest releases, among them:
  - `golang.org/x/crypto` 0.58.0, `golang.org/x/net` 0.61.0, `golang.org/x/sys` 0.49.0 and `golang.org/x/text` 0.43.0
  - `github.com/ProtonMail/go-crypto` 1.5.2, `github.com/klauspost/compress` 1.20.3 and `github.com/hashicorp/terraform-json` 0.29.0
  - `google.golang.org/grpc` 1.84.0, which the Go vulnerability database now lists as fixed for GO-2026-6443. Dependabot no longer skips grpc 1.84.

  [Change](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.3.6...v0.3.7)
- The release workflow uses `actions/upload-artifact` 7.0.2 and `actions/download-artifact` 8.0.2. CI uses `govulncheck` 1.9.0 and `golangci-lint` 2.15.0. [Change](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.3.6...v0.3.7)
- The cookbook pipeline example pins dlt 1.31.0 and refreshes its lock file, which moves `certifi` to 2026.10.19 for PYSEC-2026-4320. The customer-facing analytics backend example pins `pg` 8.23.1. [Change](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.3.6...v0.3.7)
