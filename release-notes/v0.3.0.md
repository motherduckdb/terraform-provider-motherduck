## Highlights

- Register an existing Iceberg REST catalog, such as Amazon S3 Tables or AWS Glue, as a MotherDuck database with `database_type = "iceberg"` and an `iceberg` block. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Manage the MotherDuck features released to production through 2026-09-25: `FLIGHTS` secrets, access token descriptions, the current Dive embed-session fields and Flight schedule status. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Release packages now run on Linux with glibc 2.34 or newer, including Ubuntu 22.04, Debian 12, RHEL 9 and Amazon Linux 2023, and on macOS 13 or newer. The v0.2.13 packages needed glibc 2.38 and macOS 15. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)

## Features

- `motherduck_secret` accepts a sensitive `flight_params` map for `type = "flights"` secrets. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- `motherduck_access_token` accepts an optional `description`, and `motherduck_user_tokens` returns it. MotherDuck cannot edit a description, so changing it replaces the token. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- The `motherduck_dive_embed_session` data source and ephemeral resource accept `session_name`, `version`, `required_resources` and `initial_state`. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- `motherduck_flight` reports `schedule_status` and `owner_name`, so a schedule that MotherDuck disabled is visible. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- `motherduck_flight_logs` pages on the server and accepts `order`, so lines before the last 1,000 are reachable. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- `files`, `buckets_for_secret` and `flight_logs` accept `limit` and `offset`. Every listing data source documents a deterministic row order. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)

## Bug Fixes

- Changing a share's `include_pattern` updates the share in place. Before, omitted share options forced a replacement that dropped the share, rotated its URL and lost its grants. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Respelling an imported table column type with an alias, such as `INT` for `INTEGER`, no longer replaces the table. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- A named snapshot whose database was dropped outside Terraform stays in state with a warning, and destroying it releases the retained, billed snapshot name. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Snapshot refresh follows `snapshot_id`, so a rename made outside Terraform plans an in-place rename back. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Secrets with uppercase names are found after creation, and destroying a missing secret succeeds. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Creating a view fails instead of overwriting an existing view with the same name. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Guide creation is no longer retried, which could create duplicate Guides after a timeout. A failed readback never writes unknown values to state. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Guide `references` treat an empty `schema`, `table` or `column` string the same as an omitted value. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- `motherduck_dive` reads `api_version` and `required_resources` on refresh and import, so an import no longer needs a corrective update. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- `motherduck_flight_run` keeps its state while the parent Flight exists. Before, a run that fell off the first listing page was removed and the Flight ran again. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Duckling config cooldowns record the live value, so import and refresh no longer plan an update. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Catalog row JSON keeps integers exact and renders DECIMAL, INTERVAL and nested UUID values correctly. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- The SQL client observes context cancellation while waiting for a connection, and discards a connection whose database could not be restored. The REST client never retries a POST. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)

## Compatibility

- **Stricter plan-time validation:**
  - Service account usernames need at least 3 characters.
  - The reserved token names `MotherDuck Extension` and `MotherDuck Flights` are rejected.
  - The reserved Flight config keys `MOTHERDUCK_FLIGHT_ID` and `MOTHERDUCK_FLIGHT_RUN_ID` are rejected.
  - Flight source and requirements have size limits.

  MotherDuck already rejected all of these at apply time. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- **Provider configuration:** unknown `api_base_url`, `database`, `attach_mode` and `custom_user_agent` values are now errors. Plain HTTP `api_base_url` values are accepted only for loopback hosts. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- **`motherduck_flight_logs` with `limit` set:** rows count from the start of the log instead of from the start of the last 1,000 lines. Use `order = "desc"` to read the tail. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- **Duckling config cooldowns:** removing a configured cooldown keeps the current value instead of resetting it. Set the value you want instead. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- **Deprecation:** `session_hint` on the embed session is deprecated in favor of `session_name`. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- **`motherduck_guide_grantees`:** no longer has a `granted_at` column. The data source never worked in production. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
- Guide role access remains experimental and is not yet available in MotherDuck. [Changes](https://github.com/motherduckdb/terraform-provider-motherduck/compare/v0.2.13...v0.3.0)
