## Highlights

- A newly created view remains in Terraform state when the catalog read that follows its creation returns no row or an error. [#51](https://github.com/motherduckdb/terraform-provider-motherduck/pull/51)

## Bug Fixes

- Previously, a view whose catalog read failed immediately after creation was not recorded in state, so Terraform could neither identify nor remove it after the failed apply. The view is now recorded in state, and the read error is still reported. [#51](https://github.com/motherduckdb/terraform-provider-motherduck/pull/51)

## Compatibility

- Provider schemas, import formats and supported Terraform versions are unchanged. Version constraints such as `~> 0.2.0` select this release. [#51](https://github.com/motherduckdb/terraform-provider-motherduck/pull/51)
