## Highlights

- MotherDuck now serves the updated agent usage schema to every region. Provider versions earlier than 0.4.2 fail to read the `motherduck_agent_usage` data source with this schema. This release, like v0.4.2, reads it, and the data source documentation states the version requirement. [#135](https://github.com/motherduckdb/terraform-provider-motherduck/pull/135)
- The guides and examples point at the v0.4.2 release, which includes the Azure examples and the updated `motherduck_agent_usage` attributes. [#135](https://github.com/motherduckdb/terraform-provider-motherduck/pull/135)

## Upgrading from v0.4.2

Version constraints such as `~> 0.4.0` select this release. The provider behavior is unchanged from v0.4.2. Configurations on v0.4.1 or earlier that read `motherduck_agent_usage` must upgrade, as described under [Compatibility](#compatibility).

1. Run `terraform init -upgrade`.
2. Run `terraform plan` and review the plan before applying it. Existing resources are not expected to change.
3. Update pinned refs and module sources that reference `v0.4.2`.

## Compatibility

- MotherDuck no longer reports `run_finished_ts` in agent usage. The `motherduck_agent_usage` data source of provider versions earlier than 0.4.2 filters on that column, so a read fails with `Binder Error: Referenced column "run_finished_ts" not found in FROM clause!`. Configurations that read the data source need provider version 0.4.2 or later. They should also read `end_time` instead of the deprecated `run_finished_ts` attribute, which holds the same value. [#135](https://github.com/motherduckdb/terraform-provider-motherduck/pull/135)

## Maintenance

- Guides and examples link to `v0.4.2` in tree and blob links, module sources, the `git clone` command and the GitHub installation guide. The Pulumi guide and the Pulumi Python example use provider version 0.4.2. [#135](https://github.com/motherduckdb/terraform-provider-motherduck/pull/135)
- Example dependency updates:
  - The Pulumi Python example updates `grpcio`, `googleapis-common-protos`, the OpenTelemetry packages, `semver` and `wrapt`. [#127](https://github.com/motherduckdb/terraform-provider-motherduck/pull/127)
  - The cookbook pipeline example updates `opentelemetry-api` to 1.45.2. [#132](https://github.com/motherduckdb/terraform-provider-motherduck/pull/132)
- Dependabot no longer updates the `duckdb` pin of the cookbook pipeline example, because MotherDuck does not yet accept DuckDB 2.0 clients. The pin is updated by hand when MotherDuck supports a newer DuckDB version. [#136](https://github.com/motherduckdb/terraform-provider-motherduck/pull/136)
