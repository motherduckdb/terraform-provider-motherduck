## Highlights

- The new `motherduck_dive_grant` and `motherduck_flight_grant` resources manage who can open a Dive and who can run a Flight. Each grant targets a user, a role or the whole organization. [#128](https://github.com/motherduckdb/terraform-provider-motherduck/pull/128)
- The new `motherduck_agent_usage` data source reads agent usage for the organization from `MD_INFORMATION_SCHEMA.AGENT_USAGE`, with filters by user and time window. [#128](https://github.com/motherduckdb/terraform-provider-motherduck/pull/128)

## Upgrading from v0.4.0

Version constraints such as `~> 0.4.0` select this release.

1. Run `terraform init -upgrade`.
2. Run `terraform plan` and review the plan before applying it. Existing resources are not expected to change.
3. Update pinned refs and module sources that reference `v0.4.0`.

## Features

- New `motherduck_dive_grant` resource, which grants `read` on one Dive. [#128](https://github.com/motherduckdb/terraform-provider-motherduck/pull/128)
  - `grantee_type` is `user`, `role` or `organization` and defaults to `user`. `grantee_name` names the user, service account or role, and is omitted for an organization grant.
  - The owner of a Dive and organization admins can grant and revoke access to it.
  - A grant that is revoked outside Terraform is created again by the next apply. A grant whose Dive was deleted is removed from state.
  - The import ID is `<dive_id>/<grantee_type>/<grantee_name>`, or `<dive_id>/organization` for an organization grant.
  - MotherDuck can create a Dive with a `read` grant for the whole organization. To restrict such a Dive, import that grant as `<dive_id>/organization` and remove it from the configuration.
- New `motherduck_flight_grant` resource, which grants `run` on one Flight. [#128](https://github.com/motherduckdb/terraform-provider-motherduck/pull/128)
  - It takes the same grantee arguments and import ID forms as `motherduck_dive_grant`, with `flight_id` in place of `dive_id`.
  - Only the owner of a Flight can add a grant. Organization admins can list and revoke grants.
- New `motherduck_dive_grantees` and `motherduck_flight_grantees` data sources, which list the grantee name, grantee type and privilege of every grant on one Dive or Flight. [#128](https://github.com/motherduckdb/terraform-provider-motherduck/pull/128)
- New `motherduck_agent_usage` data source. [#128](https://github.com/motherduckdb/terraform-provider-motherduck/pull/128)
  - Each row covers one agent run and reports the time the run finished, the user, the surface, the session, the run sequence number and the AI units consumed.
  - `username` filters rows by user name and ignores letter case. `start_time` and `end_time` take RFC 3339 timestamps with a time zone offset and bound the window. An `end_time` that is not later than `start_time` fails at plan time.
  - `limit` and `offset` page through rows sorted by finish time, session and run sequence number.
  - Reading agent usage requires a Business plan and query history access, which organization admins have. A permission or plan error is reported as "MotherDuck query history access required" with the steps to resolve it.
