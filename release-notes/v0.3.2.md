## Highlights

- The new `instance_type` argument on `motherduck_flight` sets the runner size of a Flight. [#71](https://github.com/motherduckdb/terraform-provider-motherduck/pull/71)
- The provider embeds DuckDB 1.5.6 and loads the matching MotherDuck extension, which MotherDuck released on 2026-10-01. [#71](https://github.com/motherduckdb/terraform-provider-motherduck/pull/71)

## Upgrading from v0.3.1

Version constraints such as `~> 0.3.0` select this release.

1. Run `terraform init -upgrade`.
2. Run `terraform plan` and review the plan before applying it. Existing Flights refresh `instance_type` from MotherDuck and plan no changes unless the argument is set.
3. Environments that block outbound downloads should review the DuckDB 1.5.6 item under [Compatibility](#compatibility) before upgrading.
4. Update pinned refs and module sources that reference `v0.3.1`.

## Features

- `motherduck_flight` has an optional `instance_type` argument that sets the runner size for manual and scheduled runs. [#71](https://github.com/motherduckdb/terraform-provider-motherduck/pull/71)
  - The sizes are `F4`, `F16` and `F32`, with 4, 16 and 32 GB of memory. The Business plan offers all three sizes, the Lite plan and free trials offer `F4` and `F16`, and the Free plan offers `F4`.
  - When the argument is omitted at creation, MotherDuck applies the plan default, which is `F16`, or `F4` on the Free plan. Terraform records the size that MotherDuck reports.
  - A change updates the Flight in place and creates a new Flight version. Removing the argument keeps the applied size.
  - The provider rejects a value that is not a MotherDuck size at plan time. Size names are case-sensitive. MotherDuck rejects a size that the plan does not offer at apply time.
- Rows of the `motherduck_flight_versions` data source include the `instance_type` of each version. [#71](https://github.com/motherduckdb/terraform-provider-motherduck/pull/71)

## Compatibility

- The provider embeds DuckDB 1.5.6 instead of 1.5.5. On first use, it downloads the MotherDuck extension built for DuckDB 1.5.6. Environments that pre-install extensions for a restricted network must add the DuckDB 1.5.6 MotherDuck extension before upgrading. [#71](https://github.com/motherduckdb/terraform-provider-motherduck/pull/71)
- Existing resource schemas, import formats and the provider source address are unchanged. `instance_type` is an addition. [#71](https://github.com/motherduckdb/terraform-provider-motherduck/pull/71)

## Maintenance

- The documentation states that MotherDuck returns up to 5,000 rows from the `motherduck_flights` and `motherduck_flight_versions` data sources when `limit` is omitted, instead of 50. Larger accounts can page with `limit` and `offset`. [#71](https://github.com/motherduckdb/terraform-provider-motherduck/pull/71)
- The `motherduck_flight` documentation lists the Flight sizes available on each plan. [#71](https://github.com/motherduckdb/terraform-provider-motherduck/pull/71)
