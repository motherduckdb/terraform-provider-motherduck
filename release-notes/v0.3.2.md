## Highlights

- Choose the runner size for a Flight with the new `instance_type` argument on `motherduck_flight`. [#PR](PR_URL)
- The provider now embeds DuckDB 1.5.6 and loads the matching MotherDuck extension, which MotherDuck released to production on 2026-10-01. [#PR](PR_URL)

## Upgrading from v0.3.1

Constraints such as `~> 0.3.0` already select v0.3.2.

1. Run `terraform init -upgrade`.
2. Run `terraform plan` and review it before applying. Existing Flights refresh `instance_type` from MotherDuck and plan no changes unless you set it.
3. If your environment blocks outbound downloads, see the DuckDB 1.5.6 item in [Compatibility](#compatibility) before you upgrade.

## Features

- `motherduck_flight` has an optional `instance_type` that sets the runner size for manual and scheduled runs. [#PR](PR_URL)
  - Sizes are `F4`, `F16`, and `F32`, with 4, 16, and 32 GB of memory. The Business plan offers all three, the Lite plan and free trials offer `F4` and `F16`, and the Free plan offers `F4`.
  - When omitted at creation, MotherDuck applies the plan default: `F16`, or `F4` on the Free plan. Terraform records the size MotherDuck reports.
  - A change updates the Flight in place and creates a new Flight version. Removing the argument keeps the applied size.
  - The provider rejects a name that is not a MotherDuck size at plan time. Size names are case-sensitive. MotherDuck rejects a size the plan does not offer at apply time.
- `data.motherduck_flight_versions` rows include the `instance_type` of each version. [#PR](PR_URL)

## Compatibility

- The provider embeds DuckDB 1.5.6 instead of 1.5.5. On first use it downloads the MotherDuck extension built for DuckDB 1.5.6. If you pre-install extensions for a restricted network, add the DuckDB 1.5.6 MotherDuck extension before you upgrade. [#PR](PR_URL)
- Existing resource schemas, import formats and the provider source address are unchanged. `instance_type` is additive. [#PR](PR_URL)

## Maintenance

- Document Flight sizes per plan in the `motherduck_flight` guide. [#PR](PR_URL)
