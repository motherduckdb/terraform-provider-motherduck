## Highlights

- Recover cleanly when a Dive or Guide is deleted outside Terraform, and get consistent diagnostics when a Flight run times out. [#33](https://github.com/motherduckdb/terraform-provider-motherduck/pull/33)

## Bug Fixes

- Recognize the service's typed missing-Dive and missing-Guide responses so plans can recreate deleted objects and cleanup can proceed. Permission, transport, and unrelated dependency failures remain visible. [#33](https://github.com/motherduckdb/terraform-provider-motherduck/pull/33)
- Stop polling at the configured Flight deadline and report the run number and last status, while preserving separate caller-cancellation diagnostics. [#33](https://github.com/motherduckdb/terraform-provider-motherduck/pull/33)

- No schema changes or configuration migration are required. Dives and Guides retain their experimental scope, and Flight-run resources remain deprecated. [#33](https://github.com/motherduckdb/terraform-provider-motherduck/pull/33)
- A stale role assignment after external service-account deletion can still require service-side cleanup. This release documents the observed limitation and preserves the failure in Terraform state. [#33](https://github.com/motherduckdb/terraform-provider-motherduck/pull/33)
