## Highlights

- Enables Dive and Flight resources and data sources by default by removing the provider-level preview opt-in for these SQL table-function workflows. [#4](https://github.com/motherduckdb/terraform-provider-motherduck/pull/4)
- Hardens Flight configuration handling so invalid runtime config names are rejected during Terraform validation and omitted `access_token_name` values no longer drift to MotherDuck's default token name during refresh. [#15](https://github.com/motherduckdb/terraform-provider-motherduck/pull/15)

## Features

- Removes `preview_features_enabled` from provider configuration, examples, generated docs, and test fixtures so Dive and Flight configurations no longer need a separate preview flag. [#4](https://github.com/motherduckdb/terraform-provider-motherduck/pull/4)

## Bug Fixes

- Validates Flight and Flight run `config` maps before calling the public Flight SQL functions, rejecting empty keys, reserved runner parameter names, `=` in keys, and NULL bytes in keys or values. [#15](https://github.com/motherduckdb/terraform-provider-motherduck/pull/15)
- Keeps `access_token_name` unset in Terraform state when it is omitted from configuration, avoiding an inconsistent result after apply when MotherDuck reports its default Flight token name. [#15](https://github.com/motherduckdb/terraform-provider-motherduck/pull/15)
- Emits typed empty `VARCHAR` list and map literals for SQL calls that pass empty Flight secret or config collections. [#15](https://github.com/motherduckdb/terraform-provider-motherduck/pull/15)

## Compatibility

- `preview_features_enabled` is no longer accepted in provider configuration; remove it from existing modules before upgrading. Dive and Flight calls still return explicit SQL-function diagnostics if the corresponding MotherDuck table function is not available to the session. [#4](https://github.com/motherduckdb/terraform-provider-motherduck/pull/4)
- Flight run config overrides must use keys declared on the Flight definition and must follow the same runtime config key constraints as Flight config. [#15](https://github.com/motherduckdb/terraform-provider-motherduck/pull/15)
