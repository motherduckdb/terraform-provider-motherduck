# motherduck_active_accounts (Data Source)

Reads preview active account and active Duckling metadata from the MotherDuck REST API.

This data source inspects existing objects without taking lifecycle ownership.
Use it after the referenced objects exist and with credentials that can read
them. See [authentication](../guides/authentication.md).

## Example Usage

```terraform
data "motherduck_active_accounts" "current" {}
```

## Schema

### Read-Only

- `accounts` (Attributes List, Sensitive) Accounts that have an active or cooling-down Duckling, sorted by username. It holds the same inventory as `accounts_json` as typed objects for expressions. Sensitive like `accounts_json` because it can reveal account and Duckling metadata, so an output that exposes it must set `sensitive = true` or wrap the value in `nonsensitive()`. (see [below for nested schema](#nestedatt--accounts))
- `accounts_json` (String, Sensitive) Raw active-account inventory returned by the MotherDuck REST API. Sensitive because it can reveal account and Duckling metadata.

- `username` (String) Username of the user or service account.

### Nested Schema for `accounts.ducklings`

Read-Only:

- `id` (String) Duckling ID. `rw` is the read-write Duckling, and `rs.N` is read-scaling replica `N`.
- `status` (String) `active` or `cooldown`.
- `type` (String) `read_write` or `read_scaling`.
