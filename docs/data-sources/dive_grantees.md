# motherduck_dive_grantees (Data Source)

Lists the users, roles, and organization that hold a grant on one MotherDuck Dive, read from `MD_LIST_DIVE_GRANTEES`. The owner always has access and is not listed. The Dive must be visible to the current principal. Rows are sorted by grantee type and grantee name.

Each row is one grant. The organization grant appears as one row with
`grantee_type` `organization` and the organization name as `grantee_name`.
A Dive that only its owner can open returns no rows.

The Dive must be visible to the current principal. MotherDuck reports a Dive
the principal cannot read as not found, and the read fails. MotherDuck names
the grantees for the owner of the Dive and for organization admins. Other
readers may see grants without grantee names. To manage the
grants, use [motherduck_dive_grant](../resources/dive_grant.md).

This data source inspects existing objects without taking lifecycle ownership.
Use it with credentials that can read them. See
[authentication](../guides/authentication.md).

## Example Usage

```terraform
data "motherduck_dive_grantees" "revenue" {
  dive_id = "123e4567-e89b-42d3-a456-426614174000"
}

output "revenue_dive_is_shared_with_the_organization" {
  value = anytrue([for row in data.motherduck_dive_grantees.revenue.rows : row.grantee_type == "organization"])
}
```
