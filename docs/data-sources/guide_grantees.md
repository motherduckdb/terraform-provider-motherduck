# motherduck_guide_grantees (Data Source)

This experimental data source lists the roles that can read a Guide with
role-scoped access. It reads the Guide's `access_role_names` column through
`MD_GET_GUIDE` and returns no rows for user or organization access.

Production MotherDuck supports only user and organization Guide access today.
Role-scoped access requires a session whose `MD_SET_GUIDE_ACCESS` accepts a
`role_names` parameter. Without it, the data source returns an explicit
unavailable-feature diagnostic. An organization-admin token alone does not make
the feature available.

Check the authenticated session before using it:

```sql
SELECT count(*)
FROM duckdb_functions()
WHERE lower(function_name) = 'md_set_guide_access'
  AND list_contains(parameters, 'role_names');
```

For documented private and organization-wide Guide visibility, see
[MD_SET_GUIDE_ACCESS](https://motherduck.com/docs/sql-reference/motherduck-sql-reference/guides/md-set-guide-access/).

## Example Usage

Use an existing Guide ID in a session that supports role-scoped Guide access:

```terraform
data "motherduck_guide_grantees" "revenue" {
  guide_id = "123e4567-e89b-42d3-a456-426614174000"
}
```
