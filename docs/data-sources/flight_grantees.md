# motherduck_flight_grantees (Data Source)

Lists the users, roles, and organization that hold a grant on one MotherDuck Flight, read from `MD_LIST_FLIGHT_GRANTEES`. The owner always has access and is not listed. The Flight must be visible to the current principal. Rows are sorted by grantee type and grantee name.

Each row is one grant. The organization grant appears as one row with
`grantee_type` `organization` and the organization name as `grantee_name`.
A Flight that only its owner can run returns no rows.

The Flight must be visible to the current principal. MotherDuck reports a
Flight the principal cannot see as not found, and the read fails. MotherDuck
names the grantees for the owner of the Flight and for organization admins. To
manage the
grants, use [motherduck_flight_grant](../resources/flight_grant.md).

This data source inspects existing objects without taking lifecycle ownership.
Use it with credentials that can read them. See
[authentication](../guides/authentication.md).

## Example Usage

```terraform
data "motherduck_flight_grantees" "refresh_crm" {
  flight_id = "123e4567-e89b-42d3-a456-426614174000"
}

output "refresh_crm_runners" {
  value = [for row in data.motherduck_flight_grantees.refresh_crm.rows : "${row.grantee_type}:${row.grantee_name}"]
}
```
