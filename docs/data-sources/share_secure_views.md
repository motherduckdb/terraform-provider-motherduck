# motherduck_share_secure_views (Data Source)

Lists every secure view on one share with `SHOW SECURE VIEWS ON SHARE`. Use it
to audit row and column policies, for example to find secure views that were
added outside Terraform or to check that every sensitive table has one.

Read it with the share owner's credentials. Any other identity receives a
share-not-found error. `replaces_table` is `true` or `false`, and `columns` is a
JSON array of the column names the secure view returns.

## Example Usage

```terraform
data "motherduck_share_secure_views" "usage" {
  share_name = "usage_share"
}

output "secure_view_names" {
  value = [
    for view in data.motherduck_share_secure_views.usage.rows :
    "${view.schema_name}.${view.view_name}"
  ]
}
```
