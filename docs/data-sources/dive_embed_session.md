# motherduck_dive_embed_session (Data Source)

Creates a short-lived Dive embed session for a service account.

~> Prefer the `motherduck_dive_embed_session` ephemeral resource for new configurations. This data source creates a credential and persists it in Terraform state.

## Example Usage

```terraform
data "motherduck_dive_embed_session" "reader" {
  dive_id      = "11111111-1111-4111-8111-111111111111"
  username     = "analytics_reader"
  session_hint = "dashboard"
}
```

## Schema

### Required

- `dive_id` (String) Dive ID. Must be a UUID with no leading or trailing whitespace.
- `username` (String) Service account username. Must be non-blank and 1-255 characters.

### Optional

- `session_hint` (String) Optional hint used to reuse the same read-scaling session across embed requests. Must be non-blank when set.

### Read-Only

- `session` (String, Sensitive) Short-lived embed session credential returned by MotherDuck. The data source persists this sensitive value in Terraform state.
