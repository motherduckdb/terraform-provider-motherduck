# motherduck_storage_info (Data Source)

Reads storage usage for the databases in the organization from `MD_INFORMATION_SCHEMA.STORAGE_INFO`, or from `STORAGE_INFO_HISTORY` when `include_history` is true. Requires an organization admin token. Rows are sorted by database name, database ID, and computation time.

Storage usage covers every database in the organization, so MotherDuck only
returns it to organization admins. Configure the provider `token` (or
`MOTHERDUCK_TOKEN`) with an organization admin token for this data source. A
non-admin token fails the read with an organization admin permission error.

By default each database has one row with its latest storage figures. Set
`include_history = true` to read every recorded computation from
`STORAGE_INFO_HISTORY`, and use `limit` and `offset` to page through long
histories. Byte counts are reported as decimal strings.

This data source inspects existing objects without taking lifecycle ownership.
Use it after the referenced objects exist and with credentials that can read
them. See [authentication](../guides/authentication.md).

## Example Usage

```terraform
# Requires a MotherDuck token for an organization admin.
data "motherduck_storage_info" "analytics" {
  database_name = "analytics"
}

output "analytics_active_bytes" {
  value = one(data.motherduck_storage_info.analytics.rows[*].active_bytes)
}
```

## Schema

### Optional

- `database_name` (String) MotherDuck database name filter.
- `include_history` (Boolean) Whether to read every recorded storage computation from `STORAGE_INFO_HISTORY` instead of only the latest one. Defaults to false.
- `limit` (Number) Maximum number of rows to return when the underlying MotherDuck catalog function supports limits.
- `offset` (Number) Number of rows to skip when the underlying MotherDuck catalog function supports offsets.

### Read-Only

- `rows` (Attributes List) Typed catalog rows for stable MotherDuck metadata. `rows_json` remains available for raw server columns. (see [below for nested schema](#nestedatt--rows))
- `rows_json` (String, Sensitive) Raw MotherDuck catalog rows encoded as JSON. Sensitive because catalog rows can include share URLs and account metadata.
