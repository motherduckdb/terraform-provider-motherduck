# motherduck_share (Data Source)

Describes one MotherDuck share with `MD_DESCRIBE_DATABASE_SHARE`. Set `name` for a share owned by the current account or `url` for any share the caller can access, including shares received from other accounts. Unlike `motherduck_shared_with_me`, this reports the source database of received shares.

Set exactly one lookup input:

- `name` reads a share owned by the account behind the token. MotherDuck does
  not resolve the name of a share received from another account.
- `url` reads any share the caller can access, including a received share.
  The URL is sensitive, so pass it through a sensitive variable or another
  sensitive value and keep it out of logs. The data source keeps the
  configured spelling of `url` instead of the canonical one MotherDuck
  reports, and redacts share URLs from error messages.

`motherduck_shared_with_me` does not report the source database of received
shares. Use this data source with the share URL to read `source_database` and
`source_database_uuid` for a received share.

`access`, `visibility`, and `update_mode` are lowercase so they compare
directly with the [motherduck_share](../resources/share.md) resource arguments.
A share that does not exist or is not visible to the caller fails the read.

This data source inspects existing objects without taking lifecycle ownership.
Use it after the referenced objects exist and with credentials that can read
them. See [authentication](../guides/authentication.md).

## Example Usage

```terraform
# Describe a share owned by the current account by name.
data "motherduck_share" "owned" {
  name = "wikipedia_pageviews"
}

# Describe a share received from another account by its URL. Keep the URL in
# a sensitive variable because unrestricted share URLs can grant access.
variable "received_share_url" {
  type      = string
  sensitive = true
}

data "motherduck_share" "received" {
  url = var.received_share_url
}

output "received_share_source_database" {
  value = data.motherduck_share.received.source_database
}
```

## Schema

### Optional

- `name` (String) Name of a share owned by the current account. Exactly one of `name` or `url` must be set. When `url` is set, this is the name MotherDuck reports for the share.
- `url` (String, Sensitive) Share URL. Exactly one of `name` or `url` must be set. Use the URL to describe a share received from another account. A configured URL keeps its configured spelling. When `name` is set, this is the URL MotherDuck reports. Sensitive because unrestricted share URLs can grant access.

### Read-Only

- `access` (String) Share access mode in lowercase.
- `created_ts` (String) Share creation timestamp reported by MotherDuck.
- `source_database` (String) Database backing the share.
- `source_database_uuid` (String) UUID of the database backing the share.
- `update_mode` (String) Share update mode in lowercase.
- `visibility` (String) Share visibility mode in lowercase.
