# motherduck_flight (Resource)

Manage a Flight's Python definition and optional schedule when Terraform is its
sole deployment owner. For application packages with previews and promotion,
use [Blueprints](../guides/blueprints-deployment.md).

## Definition and execution

`source_code` and `requirements_txt` can read version-controlled files with
`file(...)`. `config` supplies string runtime configuration. Keep credentials
out of those values and use the supported Flight secret mechanisms.

Creating or updating the definition does not mean that a data load has run or
succeeded. Configure `schedule_cron` for recurring execution, or trigger a run
through the application deployment workflow. The Flight-run Terraform resource
is deprecated.

## Lifecycle and import

Import by Flight UUID to preserve identity. Terraform reads the current
definition and then reconciles configured code and settings. Do not edit the
same Flight through both Terraform and another deployment system.

Destroy deletes the Flight definition. Verify its schedules, dependencies, and
data-retention requirements before removing it. Function availability depends
on the MotherDuck account and client.

See [resource scope](../guides/resource-scope.md).

## Example Usage

```terraform
resource "motherduck_flight" "heartbeat" {
  name            = "heartbeat"
  max_runtime_sec = 900

  config = {
    mode = "default"
  }

  source_code = <<-PY
    def main():
        print("hello")

    if __name__ == "__main__":
        main()
  PY
}
```

## Schema

### Required

- `name` (String) Flight name.
- `source_code` (String) Flight source code sent to MotherDuck.

### Optional

- `access_token_name` (String) Optional MotherDuck access token name for the Flight. When omitted, MotherDuck uses its default Flight token behavior and Terraform keeps this field unset.
- `config` (Map of String) Optional string configuration passed to the Flight. Keys become Flight runtime environment variables and must be valid Flight config names.
- `flight_secret_names` (List of String) Optional MotherDuck secret names available to the Flight.
- `max_runtime_sec` (Number) Maximum Flight runtime in seconds. `0` disables the runtime limit. When omitted, MotherDuck supplies its current default.
- `requirements_txt` (String) Optional Python requirements text for the Flight runtime.
- `schedule_cron` (String) Optional cron schedule for the Flight.

### Read-Only

- `created_at` (String) Flight creation timestamp reported by MotherDuck.
- `current_version` (Number) Current Flight version number reported by MotherDuck.
- `id` (String) Flight ID assigned by MotherDuck.
- `status` (String) Current Flight status reported by MotherDuck.
- `updated_at` (String) Flight update timestamp reported by MotherDuck.
