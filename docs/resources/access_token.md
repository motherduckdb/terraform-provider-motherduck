# motherduck_access_token (Resource)

Creates and revokes a MotherDuck access token for a user or service account.
The token secret is returned only when the token is created and cannot be
recovered during import or refresh. `ttl` is also not reconstructed from the
expiration timestamp, so omit it after importing an existing token unless you
intend to replace that token.

## Example Usage

```terraform
resource "motherduck_service_account" "app" {
  username = "analytics_app"
}

resource "motherduck_access_token" "app" {
  username   = motherduck_service_account.app.username
  name       = "terraform-managed"
  token_type = "read_write"
  ttl        = 2592000
}
```

## Import

```shell
terraform import motherduck_access_token.app 'analytics_app/<token_id>'
```

After import, run `terraform plan` with the token's name and type. Keep `ttl`
omitted to adopt an existing token without requesting replacement; Terraform
cannot recover the original lifetime or token secret.

## Schema

### Required

- `name` (String) Access token label. Must be non-blank and 1-255 characters.
- `username` (String) User or service account username. Must be non-blank and 1-255 characters.

### Optional

- `token_type` (String) `read_write` or `read_scaling`. Defaults to `read_write`. Changing this value replaces the token.
- `ttl` (Number) Optional token lifetime in seconds. Must be between 300 and 31536000. Changing this value replaces the token.

### Read-Only

- `created_ts` (String) Token creation timestamp reported by MotherDuck.
- `expire_at` (String) Token expiration timestamp reported by MotherDuck.
- `id` (String) Access token ID assigned by MotherDuck.
- `read_only` (Boolean) Whether the token is read-only according to MotherDuck.
- `token` (String, Sensitive) Token secret, returned only at creation time.
