# motherduck_share (Resource)

Manages a MotherDuck database share.

Use this resource when Terraform owns the share name, source database, access mode, visibility, update mode, and optional catalog include patterns. Name, source, access, visibility, and update mode are replacement-only. Include patterns update in place with `ALTER SHARE`.

The computed `url` attribute is sensitive. Treat share URLs as access-bearing infrastructure metadata, especially for unrestricted shares. Terraform still stores sensitive values in state, so use an encrypted backend with restricted access and pass share URLs to downstream systems intentionally through sensitive outputs or a secret manager.

## Example Usage

```terraform
resource "motherduck_database" "analytics" {
  name = "analytics"
}

resource "motherduck_share" "analytics" {
  name            = "analytics_share"
  source_database = motherduck_database.analytics.name
  access          = "restricted"
  visibility      = "hidden"
  update_mode     = "manual"
  include_pattern = ["main.reporting_*", "main.dim_*"]
}

resource "motherduck_share_grant" "reader" {
  share    = motherduck_share.analytics.name
  username = "reader_user"
}
```

## Schema

### Required

- `name` (String) Share name.
- `source_database` (String) Database to share.

### Optional

- `access` (String) Share access mode: `organization`, `restricted`, or `unrestricted`.
- `include_pattern` (List of String) Optional preview catalog include patterns. Null shares the entire database; an empty list shares no objects. Changes are applied in place. The MotherDuck client must have filtered shares enabled.
- `update_mode` (String) Share update mode: `manual` or `automatic`.
- `visibility` (String) Share visibility mode: `discoverable` or `hidden`.

### Read-Only

- `created_ts` (String) Share creation timestamp reported by MotherDuck.
- `id` (String) Share resource ID. This is the share name.
- `url` (String, Sensitive) Share URL reported by MotherDuck. This is sensitive because unrestricted share URLs can grant access.
